# 本机中文转写方案

目标：新用户装好 Aplo，不填任何 Key，点“开始录制”就能看到中文逐字稿，并能在会中问 AI。

读代码和实测日期：2026-11-27。测试用 9 分钟中文会议录音，在 Mac mini 上跑，和机器生成的对照稿比较，数字是“差异率”，不是严格错字率。

## 实测结论（已有数据）

| 模型 | 差异率 | 9 分钟录音转完 | 每 5 秒一段的延迟 | 下载 |
|---|---|---|---|---|
| Qwen3-ASR 0.6B 4 位（Aplo 代码里已列出） | 10.1% | 22 秒 | 0.1 秒 | 约 600 MB |
| Qwen3-ASR 1.7B 8 位 | 10.1% | 42 秒 | 0.31 秒 | 约 2.5 GB |
| FireRedASR2 | 13.9% | 148 秒 | 0.42 秒 | 约 2.5 GB |
| SenseVoice / Fun-ASR-Nano | 测试工具问题，未测出 | | | |

选 Qwen3-ASR 0.6B。大一号的版本没有更准。测试用的是 `mlx-audio` 里的同一个模型，Aplo 用的是另一个打包版本，准确度需要在 P0 里再核对一次。

## 现状：为什么 Aplo 里本机 Qwen3 不能用

1. **Swift 部分没接这个模型。**`crates/transcribe-soniqo/swift-lib/Package.swift` 的依赖里没有 `Qwen3ASR`，加载时直接报“需要 macOS 15”。
2. **Rust 把它标成“永远不可用”。**`model.rs` 里 `is_available_on_current_platform` 对 Qwen3 一律返回否，所以设置页里不会出现它。
3. **本机模型里能边开会边出字的只有 Parakeet，**而它只支持 25 种欧洲语言，不含中文。所以现在用本机模型开中文会，会中没有逐字稿。
4. **依赖版本偏旧。**Swift 依赖 `speech-swift` 锁在 0.0.27，最新版声明要求 macOS 15。Aplo 的部署目标是 macOS 14.2，README 已写“需要 macOS 15 或更新”。
5. **Apple 自带语音识别已经接入，**不用下载、能实时出字，但需要 macOS 26 以上。中文效果没测过。

## 做什么

### P0 验证（先做，几个小时）
- 国内镜像（hf-mirror、魔搭）上有没有 Aplo 用的那个模型仓库 `aufklarer/Qwen3-ASR-0.6B-MLX-4bit`。没有的话，下载方案要换。
- 按说话停顿把同一段录音切成一句一句再转写，看差异率有没有变差。这决定“一句一句出字”能不能用。
- 在 Mac mini（macOS 27）上测 Apple 自带语音识别的中文效果。
- 以上任何一项不达标，先停下来和你商量，不往下做。

### P1 让 Qwen3 能用
- 升级 `speech-swift`，引入 `Qwen3ASR`。
- Swift 部署目标改为 macOS 15。
- 去掉“永远不可用”的判断，改为运行时检查系统版本。
- 补单元测试。编译只在 Mac mini 上做。

### P2 会中分句出字
- `speech-swift` 的 Qwen3 只有整段转写，没有流式。用已有的语音端点检测（`SpeechVAD`，已在依赖里）判断一句话说完，每句说完就转写这一句。
- 效果：一句一句出现，说完后 0.1 到 0.5 秒出字。不会一个字一个字地跳。
- 接到现有的逐字稿和“随便问”，不改它们的界面。

### P3 下载走国内镜像
- 设置下载地址环境变量 `HF_ENDPOINT`（`speech-swift` 支持）。
- 下载 600 MB 要显示进度，可以在后台下，用户先去做别的。
- 镜像是第三方服务，可能不稳定，要保留“官方源”作为备选。

### P4 隐藏对中文没用的本机模型
- 中文界面里隐藏 Parakeet 这类只支持欧洲语言的模型。只隐藏，不删代码。

### P5 首次引导
- 默认选本机模型。macOS 26 以上且 Apple 自带中文达标的话，优先用 Apple 自带，免下载。
- 边下载模型边带用户认录音状态，不让他干等。
- 云服务（阿里云）放到之后，作为“想要更准”的可选项。

## 风险

| 风险 | 应对 |
|---|---|
| 升级 `speech-swift` 影响其他模型（比如 Parakeet 流式） | 升级后跑全部本机模型的现有测试 |
| 部署目标改成 macOS 15 | README 已声明不支持 macOS 14，影响很小。发布说明里写一句 |
| 分句后准确度下降 | P0 先测，不达标就停 |
| MLX 相关文件打包遗漏 | 按 CLAUDE.md 的打包检查清单核对 |
| 镜像下载不稳定 | 保留官方源，下载失败时用中文提示 |

## 谁来做

P0 到 P3 在 Mac mini 上做（Swift 和 Rust 编译只在那台机器上）。启动一个 Agent，工作目录 `~/Projects/aplo`，我先把任务书和验收标准写好。P4、P5 在 MacBook 上做。每一步都先给你看结果再往下。

录音相关的最终验证需要你在 MacBook 上做：装好包，点开始录制，看有没有字。
