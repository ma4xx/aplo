**让 AI 也参加你的会。** 在会议室里打开 Mac，开会时 AI 和你一起听，随时帮你理解；散会后，整场会议直接交给你的 Agent，接着去做。

## 会上：AI 和你一起听

开会时随时打字问它，不用切窗口，也不用等散会。

> **10:12 老板**：下半年不能只盯着拉新了。用户来了留不住，前面花的钱都白花……
>
> **你问**：老板刚才讲的这个，你怎么理解？
>
> **AI**：他想把重点从拉新转到留存，方向定了，但还没给具体指标。接下来值得先确认：留存看哪个数，目标定多少，哪些现有的拉新投入要收。
>
> **10:14 老板**：大家怎么看？
>
> <sub>示例</sub>

- **跟着会议回答**：你问的时候，它知道这场会到现在说了什么。
- **按你的方式讲**：它的角色和说话方式可以自己设定，回答贴近你的岗位和习惯。
- **知道来龙去脉**：同一件事的会放在一起，前几场的结论它都记得。

## 会后：交给你的 Agent

Agent 已经在帮你写文档、推进任务，它缺的只是会上发生了什么。

- **直接交给它**：Codex、Claude Code 这类 Agent 直接读会议，不用导出转发。
- **它本来就懂你的工作**：拿到会议后，结合它已经了解的项目和习惯，就能接着做。
- **原话都在**：完整的逐字稿也能读，不只是一份摘要。

> **你对 Agent 说**：读一下刚才那场会，按会上定下来的调整方案。
>
> <sub>示例。Agent 读取会议，再去改你的方案文档</sub>

## 记录在你手里

- **默认存在本机**：会议、逐字稿、录音都在你自己的电脑上。让哪个 AI 读，由你决定。
- **AI 由你选**：本机模型、自己的 Key，或者已有的 ChatGPT 订阅，随时可以换。

## 开始使用

需要 Apple 芯片的 Mac，macOS 15 或更新。

1. **下载并安装**：在 [Releases](../../releases/latest) 下载 `Aplo-*-macos-arm64.tar.gz`，解压后把 `Aplo.app` 拖进“应用程序”。
   - 第一次打开：在 `Aplo.app` 上右键，选“打开”。应用还没有苹果公证，系统会拦一次。
   - 较新的 macOS 里如果没有“打开”按钮，到“系统设置 → 隐私与安全性”，拉到最下面点“仍要打开”。
2. **允许麦克风**：会议室里的会靠麦克风录。线上会议还需要允许系统音频，才能录到对方的声音。
3. **选择转写和 AI**：填入你自己的服务 Key，或者用已有的 ChatGPT 订阅登录，也可以用本机模型。还没有转写服务的话，看下面的 [用阿里云百炼注册并获取 Key](#没有转写服务的-key用阿里云百炼)。
4. **进会议室，点开始录音**：把 Mac 放在桌上，尽量离说话的人近一些。开会时随时在旁边打字问 AI。
5. **散会后，交给你的 Agent**：第一次使用时，在“设置 → 连接 AI 助手”里点“复制配置说明”，发给你的 Agent，它会自己配好，只需要做一次。详细步骤看下面的 [让你的 Agent 读会议](#让你的-agent-读会议)。之后直接让它读会议。

## 没有转写服务的 Key？用阿里云百炼

Aplo 需要一个“转写服务”把录音变成文字。如果你手上没有，可以去 [阿里云百炼](https://bailian.console.aliyun.com/) 注册一个账号，新用户有免费额度，可以直接用来转写。下面是从零开始的步骤。

> **关于免费额度**：阿里云的规则是新用户每个模型有一份免费额度，从开通起 **90 天**内有效，**只有“华北2（北京）”地域有**，并且需要先完成**实名认证**。具体每个转写模型给多少，阿里云文档里没有写清楚，以你控制台里显示的为准。规则以阿里云官网为准，可能会调整。

### 第 1 步：注册并开通

1. 打开 <https://bailian.console.aliyun.com/>，用阿里云账号登录。没有账号的话，按页面提示注册一个。
2. 按提示完成**实名认证**（领取免费额度需要）。
3. 登录后确认页面左上角的地域是**华北2（北京）**。

### 第 2 步：创建 API Key

1. 打开 API Key 页面：<https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key>。
2. 点“**创建 API Key**”，弹窗里保持默认选项，点“确定”。
3. **马上复制**生成的 Key。阿里云只在创建成功时显示一次完整的 Key，没复制的话只能重新创建。
4. 这串 Key 相当于你的账号密码，不要发给别人，也不要发到网上。

### 第 3 步：填进 Aplo

1. 打开 Aplo，进入“**设置 → 转写**”。
2. 在“配置服务商”列表里找到 **Alibaba Cloud Model Studio**，点开。
3. 把刚才复制的 Key 粘贴到“**API 密钥**”。
4. **一定要改这一步**：展开“**高级**”，把 **Base URL** 改成 `https://dashscope.aliyuncs.com`。
   Aplo 默认填的是国际站地址，而你在国内站（北京）创建的 Key 不能用在国际站，不改的话会一直报错。
5. 回到页面上方的转写选择框，选择服务商 **Alibaba Cloud Model Studio**，再选一个模型。我自己用的是 `qwen-audio-3.1-asr-flash-streaming`。
6. 新建一条笔记，点开始录音，对着电脑说几句话，看到文字出现就成功了。

### 遇到问题

- **一直报错或没有文字**：先检查 Base URL 有没有改成 `https://dashscope.aliyuncs.com`，Key 是不是在“华北2（北京）”创建的。
- **提示没有权限调用模型**：阿里云要求语音识别类模型在百炼控制台里单独开通。到控制台的“模型广场”找到这个模型，按提示开通后再试。
- **额度用完了**：免费额度用完或过期后，按阿里云的价格自动扣费，需要在阿里云账户里充值。费用和用量请到阿里云控制台查看。

## 让你的 Agent 读会议

这一步让 Codex、Claude Code 这类 Agent 能直接查阅你的会议纪要和逐字稿，不用你复制粘贴。只需要做一次，之后每次开完会，直接对它说“读一下刚才那场会”就行。

**开始之前：**
- 已经装好并打开过 Aplo。连接用的小程序会在 Aplo 启动时自动装好。
- Agent 要运行在**同一台 Mac** 上，因为它读取的是这台电脑里的会议。
- 这个 Agent 要支持连接外部工具（MCP）。Codex、Claude Code 都支持。

### 第 1 步：确认连接器已就绪

打开 Aplo，进入“**设置 → 连接 AI 助手**”。页面上“第 1 步 · 自动完成”应该显示连接器已安装，一般不用你操作。如果显示没有安装，点旁边的安装按钮装一次。

### 第 2 步：复制配置说明，发给你的 Agent

1. 在同一个页面，找到“第 2 步 · 必做”，点“**复制配置说明**”。右下角会提示“已复制，粘贴发给你的 AI 助手即可”。
2. 打开你的 Agent（比如在终端里打开 Claude Code，或者打开 Codex），把刚才复制的内容**直接粘贴发给它**。
3. 它会自己把 Aplo 加进它的工具设置里，然后告诉你配置写在哪个文件、需不需要重启或者新开一个对话。按它说的做。
4. 配置生效后，它会列出你最近的 3 场会议。看到会议列表，就说明连接成功了。

这段说明是写给 Agent 看的，里面已经包含了要添加的内容，你不用看懂，也不用自己改任何配置文件。

### 第 3 步（可选）：安装技能

在同一个页面的“第 3 步 · 可选”里，点“**安装到所有智能体**”，会把一份使用说明装进 Claude Code、Codex、Cursor、OpenCode，让这些 Agent 更清楚该怎么读会议。不装也能用。

### 怎么用

连接成功后，你可以直接对 Agent 说：

- “读一下刚才那场会，按会上定下来的调整方案。”
- “看一下我这周所有关于‘下半年规划’的会，整理成待办。”
- “把昨天那场会的逐字稿里，老板提到留存的部分找出来。”

### 需要知道的

- **内容只在你的电脑上**：Agent 通过本机的小程序只读取会议，不经过任何服务器，也不需要账号。
- **Agent 不会直接改你的纪要**：它提出修改后会停在“待审”，要你在 Aplo 里确认才会生效。
- **读到的会议内容会发给这个 Agent 背后的 AI 服务**：你让哪个 Agent 读，内容就会发给它的服务商。会议里有敏感内容时请留意。
- **让 Agent 导入录音会产生转写费用**：这个操作会调用你配置的转写服务。
- **配置失败怎么办**：把 Agent 的报错原文发回给它，让它自己排查。Agent 找不到 Aplo 的话，先确认 Aplo 打开过，并且是在同一台 Mac 上操作。

## 为什么做 Aplo

我是产品经理，每天要开好几场会，和老板对需求，和同事对方案。

以前开完会，大家各自把结论记在脑子里。现在有了 AI，事情推得更快，会也更多，光靠脑子已经记不住。

我平时用 Agent 干活。可每次开完会，想让它接着推进，都得先把会上的事口述一遍给它听。线上会议还有一份自动纪要可以转给它，会议室里的会什么都没留下。

还有些时候，老板讲的是方向，我在会上没完全听懂，会后推进起来就没底。

所以我做了 Aplo，让 AI 也参加我的会：会上听不懂，马上就能问；散会后，整场会议直接交给 Agent。

—— Max

## 常见问题

<details>
<summary><strong>和腾讯会议、飞书会议有什么区别？</strong></summary>

它们主要服务线上会议，会后给大家一份纪要。Aplo 主要为会议室里的会做：打开 Mac 就能录，开会时你可以随时问 AI，散会后你自己的 Agent 能直接读这场会。
</details>

<details>
<summary><strong>线上会议能用吗？</strong></summary>

能。在飞书、腾讯会议里开会时，Aplo 同时录电脑里放出来的声音和你的麦克风。
</details>

<details>
<summary><strong>会上问 AI，别人看得到吗？</strong></summary>

看不到。提问和回答只显示在你自己的电脑上。
</details>

<details>
<summary><strong>“按你的方式讲”怎么设置？</strong></summary>

在“设置 → 会中参谋”里，用一段文字写下你希望 AI 扮演的角色和回答方式，比如回答多长、侧重什么。可以随时修改、关闭或恢复默认。
</details>

<details>
<summary><strong>哪些 Agent 能读我的会议？</strong></summary>

Codex、Claude Code 这类支持连接外部工具（MCP）的 Agent。它需要运行在你自己的这台电脑上。
</details>

<details>
<summary><strong>一定要自己申请 API Key 吗？</strong></summary>

不一定。可以用已有的 ChatGPT 订阅登录来当 AI 用，也可以用本机模型，这两种都不需要 Key。
</details>

<details>
<summary><strong>我的会议会被上传吗？</strong></summary>

Aplo 把会议存在你的电脑上（`~/Library/Application Support/aplo`）。如果你选了云端的转写服务，录音会发给那家服务商做转写；你让哪个 AI 读会议，被读到的内容就会发给它。想完全留在本机，转写和 AI 都选本机模型。
</details>

<details>
<summary><strong>在会议室录音，要告诉大家吗？</strong></summary>

要。录音前请告诉在场的人，应用里有一句现成的告知语。
</details>

<details>
<summary><strong>会议室里人多、离得远，转写准吗？</strong></summary>

取决于说话人离 Mac 多远、房间吵不吵，以及你选的转写服务。建议把 Mac 放在桌子中间。不同转写服务效果不同，可以在设置里换着试。
</details>

<details>
<summary><strong>能分享给同事吗？有 Windows 版吗？</strong></summary>

目前是个人使用，要分享可以把纪要导出成 Markdown。暂时只有 Mac（Apple 芯片）版本。
</details>

## 从源码构建

macOS，Apple 芯片。需要完整的 Xcode（含 Metal 工具链）、Node 22、pnpm，以及 `rust-toolchain.toml` 里指定的 Rust 版本。

```bash
pnpm install --frozen-lockfile
cd packages/ui && pnpm run build && cd ../..
cd apps/desktop && pnpm exec tauri build --bundles app
```
